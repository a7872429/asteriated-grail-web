# Asteriated Grail web

Public frontend for BP, Fearless, CM01, RD+BP and Re.星杯戰爭 drafting modes.

Version 2.11 adds the five-match Re.星杯戰爭 story mode, compact WebP chibi artwork, and responsive mobile draft/result layouts.

## Configuration

Deploy the private Worker first, then replace the placeholder URL in `config.js` with its `workers.dev` URL. Enable GitHub Pages from the repository root on the `main` branch.

The frontend contains character names and images only. Scoring, recommendations, AI decisions and matchup data are provided by the private backend API.
